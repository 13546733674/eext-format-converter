# Конвертер форматов

Расширение для EasyEDA / JLCEDA Professional Edition, которое конвертирует файлы библиотек Xpedition (Mentor Graphics / Siemens EDA) в формат EasyEDA Pro и импортирует их.

## Функции

- **Импорт файлов Xpedition**：поддержка импорта файлов библиотек Xpedition в формате ZIP (содержащих файлы PSK/CEL/PDB/символов)
- **Экспорт файлов Xpedition**：экспорт библиотек EasyEDA Pro в совместимый с Xpedition формат
- **Мастер импорта/экспорта**：графический интерфейс мастера для руководства пользователем через процесс конвертации форматов
- **Действия после конвертации**：
  - Импорт в Pro — прямая загрузка результата конвертации в текущий открытый EasyEDA Pro
  - Скачать файл библиотеки — сохранить сконвертированный файл `.elibz2` локально

## Использование

1. Установите это расширение в EasyEDA Professional Edition
2. Откройте мастер через меню **Конвертер форматов → Мастер импорта/экспорта**
3. Выберите «Импорт файлов Xpedition» или «Экспорт файлов Xpedition»
4. Следуйте инструкциям мастера для завершения операции

## Поддерживаемые форматы файлов

| Формат | Описание                                                                        |
| ------------ | --------------------------------------------------------------------------------------- |
| `.zip`     | Архив, содержащий файлы библиотек Xpedition (импорт) |
| `.elibz2`  | Формат файла библиотеки EasyEDA Pro (вывод)                   |

## Разработка

```shell
# Установка зависимостей
npm install

# Компиляция
npm run compile

# Упаковка
npx ts-node build/packaged.ts
```
