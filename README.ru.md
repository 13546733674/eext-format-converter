# Конвертер форматов v1.0.2

Расширение для EasyEDA / JLCEDA Professional Edition, которое конвертирует файлы между различными форматами EDA и EasyEDA Pro, включая Xpedition, Cadstar, Fabmaster, P-CAD, Allegro, gEDA, TinyCAD, а также экспорт в KiCad.

## Функции

- **Импорт нескольких форматов**：импорт файлов Xpedition (ZIP-пакет библиотек), Cadstar, Fabmaster, P-CAD, Allegro, gEDA и TinyCAD в библиотеки или проекты EasyEDA Pro
- **Экспорт в KiCad**：прямой экспорт текущего документа библиотеки символов/посадочных мест в `.kicad_sym` / `.kicad_mod` через верхнее меню
- **Экспорт файлов Xpedition**：экспорт библиотек EasyEDA Pro в совместимый с Xpedition формат
- **Мастер импорта/экспорта**：графический интерфейс мастера для руководства пользователем через процесс конвертации форматов
- **Действия после конвертации**：
    - Импорт в Pro — прямая загрузка результата конвертации в текущий открытый EasyEDA Pro
    - Скачать файл библиотеки — сохранить сконвертированный файл `.elibz2` локально

## Использование

1. Установите это расширение в EasyEDA Professional Edition
2. Откройте мастер через меню **Конвертер форматов → Мастер импорта/экспорта...**
3. Выберите формат для импорта или экспорта
4. Следуйте инструкциям мастера для завершения операции

## Поддерживаемые форматы файлов

| Направление | Формат           | Описание                                                      |
| ----------- | ---------------- | ------------------------------------------------------------- |
| Импорт      | `.zip`           | ZIP-архив с файлами библиотек Xpedition (PSK/CEL/PDB/символы) |
| Импорт      | `.zip/.cpa`      | Файл Cadstar PCB                                              |
| Импорт      | `.zip/.txt/.fab` | Файл Fabmaster PCB                                            |
| Импорт      | `.zip/.pcb`      | Файл P-CAD / gEDA PCB                                         |
| Импорт      | `.zip/.dsn`      | Файл схемы TinyCAD                                            |
| Экспорт     | `.zip`           | Пакет библиотек в формате Xpedition                           |
| Экспорт     | `.zip`           | Пакет библиотек в формате KiCad (`.kicad_sym` + `.kicad_mod`) |

Для Xpedition файлы библиотек необходимо сначала преобразовать в ASCII и упаковать в ZIP с помощью инструмента упаковки. Подробности см. в [README упаковщика](https://github.com/easyeda/eext-format-convert/blob/main/tools/xpedition-library-packager/README.md).
